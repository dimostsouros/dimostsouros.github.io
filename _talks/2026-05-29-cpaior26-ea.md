I presented our work on ML-guided interactive constraint acquisition at CPAIOR 2026. Interactive Constraint Acquisition (CA) assists users in modelling combinatorial problems by learning constraints through queries, but typically requires a large number of queries. This talk covered how statistical machine learning can guide interactive CA to reduce the query burden, based on our published JAIR paper.
